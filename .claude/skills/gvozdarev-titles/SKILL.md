# Заголовки Гвоздарева

Ты ставишь дизайнерские заголовки в готовый (уже нарезанный) вертикальный ролик, где человек говорит в камеру.
Всё рендерит один скрипт `scripts/titles.py` по плану `plan.json`. Твоя работа: понять, ЧТО человек говорит,
придумать короткий текст заголовка, выбрать стиль, поставить его точно по словам, проверить кадры и отдать ролик.

## 0. Установка (один раз)

```bash
pip install "rembg[cpu]" opencv-python-headless playwright
ffmpeg -version                  # нужен ffmpeg в PATH (Mac: brew install ffmpeg, Windows: winget install ffmpeg)
```
Заголовки рисуются в браузере: скрипт сам берёт установленный **Google Chrome**. Если Chrome нет:
`python -m playwright install chromium`. При первом запуске rembg скачает модель вырезания человека (176 МБ) в `~/.u2net`.
Python 3.10–3.14. Шрифты уже лежат в `fonts/` (бесплатные, с кириллицей), ставить ничего не нужно.

## 1. Четыре стиля

| `style` | как выглядит | когда ставить |
|---|---|---|
| `grain` слово из зерна | одно слово капсом огромно за головой, буквы по очереди собираются из зернистой пыли и уходят в пыль | **хук** (первые 1–3 с) и 1–2 главных слова ролика |
| `archive` «Дизайн архив» | заглавная пишется каллиграфией, рядом жирный гротеск в 2 строки, одна буква 2-й строки рукописная; квадрат выпрыгивает → стрелка вправо и подпись; ®; мелкие строки и крупный призыв на груди | глава, «собранная» мысль, дизайн, бренд, экспертный тезис; призыв в конце |
| `button` «Пуговка» | 1-я строка контуром, 2-я с антиквенной заглавной; маленький овал-«пуговка» с коротким словом сцепляет строки и защёлкивается последним; DIN-строки печатаются по буквам | хлёсткая фраза из 3 слов («Все · мои · Правила», «Даже · в · Субтитры»), анти-правило, вывод |
| `ransom` буквы-вырезки | фон становится бумагой в клетку, человек вырезан с белой кромкой, слова собираются из журнальных букв, уход рваным краем | громкий тезис, хулиганская мысль, «твой бренд», разговорный ролик; 1–2 коротких слова |

Чередуй стили. В одном ролике: хук `grain` + 2–3 заголовка разных стилей. Один и тот же стиль подряд надоедает.

## 2. Порядок работы

1. **Слова со временем.** Нужна расшифровка с таймкодами слов. Если её нет: Whisper с `word_timestamps=True`
   (Mac: `mlx-whisper`, Windows/Linux: `faster-whisper`). Длинный файл режь по паузам и расшифровывай кусками,
   иначе Whisper склеивает повторы.
2. **Найди моменты.** Заголовок = начало новой мысли, главы, перечисления («первый…», «второй…»), вывод, призыв.
   Не чаще раза в 5–8 секунд. Окна заголовков не пересекаются.
3. **Придумай текст** (правила в §3). Покажи человеку 2–3 варианта текста и стиль на каждый момент, дай выбрать.
4. **Окно:** `t0` = начало первого слова фразы (можно на 0.1 с раньше), `t1` = конец мысли + 0.3–0.5 с.
   Заголовок живёт 3–6 с, уход (размытие вверх) занимает последние 0.45 с — не обрезай его.
   Мелкие строки на груди появляются по словам: `small_at` / `big_at` — секунды ОТ `t0`.
5. **Напиши `plan.json`** (пример: `examples/plan.json`, все настройки: `reference/TITLES.md`).
6. **Контакт-лист до рендера:** `python scripts/titles.py plan.json --sheet` → `<output>_sheet.jpg`.
   Открой и проверь: текст не на лице, ничего не режется краем, строки на груди лежат на одежде, буквы не слиплись.
7. **Рендер:** `python scripts/titles.py plan.json`. Звук исходника сохраняется. Черновик быстрее: `--fast` (без моушн-блюра).
   Около 1–2 с рендера на кадр заголовка, кадры без заголовков идут быстро.
8. **Проверь стыки** (кадры вокруг `t0` и `t1` каждого заголовка) и покажи человеку контакт-лист и ролик.
   Правки: `--only 2,3` рендерит только эти заголовки (номера по порядку в плане).

## 3. Текст заголовка (важнее анимации)

- **Коротко.** `archive`: 2 строки по 1 слову («Дизайн / свежий», «Мой / метод»). `button`: 3 слова, среднее — короткое
  связующее («Все · мои · Правила»). `grain`: 1 слово до 10 букв. `ransom`: 1–2 слова до 6 букв.
- **Слово из речи.** Заголовок повторяет или сжимает то, что человек говорит в эту секунду. Не придумывай новый смысл.
- **Подпись** (`label`) в `archive` — бренд или рубрика латиницей капсом: `STUDIO`, `ВАШ_НИК`, `PART 02`.
- **Мелкие строки** — контекст капсом (о чём глава, дата, «ПЕРВЫЙ ЗАГОЛОВОК»). **Крупная строка** (`big`) — призыв
  или итог: «ПИШИ «ТЕКСТ»», «ДИЗАЙНЕРСКИЙ».
- Рукописная буква в `archive` ставится сама на е/н/в/о. Если буква выглядит странно — `"hand": 2` (номер буквы)
  или `"hand": false`.

## 4. Правила вкуса (иначе выглядит как дешёвый AI-монтаж)

- **Текст никогда не на лице.** Брови, глаза, рот свободны. Крупный текст не выше y≈300 (сверху интерфейс Instagram)
  и не ниже y≈1650 (снизу подпись и кнопки).
- **За человеком, а не поверх.** Крупный блок встаёт ЗА головой по маске, мелкие строки — спереди на груди.
  Это и даёт «дорого». Если голова в кадре маленькая и текст её не касается — тоже нормально.
- **Белый с мягкой тенью.** Красный и другие яркие цвета на тёплом фоне сливаются. Цвет меняй, только если фон
  светлый и белый не читается (`"color": "#141414"`, тень `"shadow": 0`).
- **Без тёмной пелены** под текстом. Читаемость даёт тень букв, а не затемнённый кадр.
- **Плавно, без обрывов.** Заголовок сам входит и сам уходит. Не ставь следующий заголовок раньше, чем ушёл прошлый.
- **Звук обязателен** (тихий, на 15–25 дБ тише голоса). Что ставить: `reference/TITLES.md` §«Звук».
  Никаких бумов и импактов.

## 5. Если что-то не так

- Строки на груди легли на лицо или на стол: задай `"chest_y": 1350` (пиксели сверху, кадр 1080×1920).
- Блок слишком большой/маленький: `"width": 700` (по умолчанию 770–780), сдвиг вниз: `"top": 340`.
- Буквы 2-й строки слиплись с 1-й: `"gap2": 30` (раздвинуть строки, по умолчанию скрипт раздвигает сам при й/ё и р/у/д).
- Маска цепляет кресло или предмет за спиной: `"mask_model": "u2net"` или `"isnet-general-use"` в plan.json.
- Свой шрифт: `"fonts": {"sans": "путь.ttf"}` или системный `"fonts": {"sans": "system:Helvetica Neue"}`
  (ключи: `sans`, `script`, `serif`, `cond`).
- Нет браузера: поставь Google Chrome или `python -m playwright install chromium`.
- Исходник горизонтальный: скрипт обрежет его по центру до 9:16. Если человек не в центре — сначала сделай кроп сам.
