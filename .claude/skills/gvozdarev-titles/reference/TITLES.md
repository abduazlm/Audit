# Все настройки заголовков

Кадр 1080×1920. Время `t0`/`t1` — секунды исходника. `small_at`, `big_at`, `pin_at`, `line2_at` — секунды от `t0`.
Общие поля любого заголовка: `style`, `t0`, `t1`, `color` (цвет крупного блока, `#FFFFFF`), `shadow` (тень блока, 0.55; 0 — без тени),
`behind` (true — блок за человеком, false — поверх).

## grain — слово из зерна

```json
{"style": "grain", "t0": 0.0, "t1": 2.6, "word": "ЗАГОЛОВКИ"}
```
| поле | что | по умолчанию |
|---|---|---|
| `word` | одно слово капсом (пробел можно, будет неразрывный) | — |
| `y` | центр слова по высоте | 430 |
| `size` | кегль; сам уменьшится, чтобы слово влезло в 1000 px | 300 |
| `font` | `cond` (узкий жирный) или `sans` (гротеск) | `cond` |

Буквы появляются по очереди через 0.06 с: слово из 9 букв собирается за ~1.5 с. Ставь `t0` на 0.1–0.2 с раньше слова.
Часть букв специально остаётся с лёгкой пылью по краю — так задумано.

## archive — «Дизайн архив»

```json
{"style": "archive", "t0": 5.0, "t1": 10.5, "line1": "Дизайн", "line2": "свежий", "label": "STUDIO",
 "small": ["ПЕРВАЯ МЕЛКАЯ СТРОКА", "ВТОРАЯ, ЕЩЁ МЕЛЬЧЕ — 2026"], "big": "ДИЗАЙНЕРСКИЙ", "small_at": 1.4, "big_at": 2.6}
```
| поле | что | по умолчанию |
|---|---|---|
| `line1` | 1-я строка; первая буква пишется каллиграфией | — |
| `line2` | 2-я строка, жирный гротеск | — |
| `hand` | номер буквы `line2` (с 0), которая рукописная; `false` — без неё | авто (е/н/в/о/и/а) |
| `label` | подпись над 1-й строкой (выезжает из квадрата) | пусто |
| `small` | 1–2 мелкие строки на груди | нет |
| `big` | крупная строка на груди (призыв) | нет |
| `small_at` / `big_at` | когда появляются строки на груди | 30 % окна / +0.9 с |
| `top` | верх блока | 300 |
| `width` | ширина блока | 770 |
| `chest_y` | высота мелких строк | авто по плечам |
| `gap2` | раздвинуть строки (px макета) | авто |
| `tracking` | трекинг гротеска | −0.06 |

Каллиграфическая заглавная: хорошо выглядят Д, В, М, Б, Л, Р, С. Если буква странная — переставь слова или возьми другое.
На призыве (`big_at`) стрелка «кивает» вперёд — ставь `big_at` на слово «пиши/жми/смотри».

## button — «Пуговка»

```json
{"style": "button", "t0": 11.0, "t1": 16.5, "line1": "Даже", "pin": "в", "line2": "Субтитры",
 "line2_at": 0.4, "pin_at": 0.9, "small": "ТРЕТИЙ ЗАГОЛОВОК . ТИПОГРАФИКА", "big": "ПИШИ «ТЕКСТ»", "small_at": 1.6, "big_at": 2.8}
```
| поле | что | по умолчанию |
|---|---|---|
| `line1` | 1-я строка, контурный курсив | — |
| `pin` | короткое слово в овале-пуговке (1–4 буквы); пусто — без пуговки | пусто |
| `line2` | 2-я строка: первая буква антиквой, остальное жирный курсив | — |
| `line2_at` | когда падает 2-я строка | 0.36 |
| `pin_at` | когда защёлкивается пуговка (последней!) | `line2_at` + 0.3 |
| `small` | мелкая DIN-строка, печатается по буквам | нет |
| `big` | крупная DIN-строка, печатается по буквам | нет |
| `top`, `width`, `chest_y` | как в archive | 310, 780, авто |
| `kern` | зазор между антиквенной заглавной и строкой | 0.07 |

Пуговка встаёт под центр 1-й строки на стык строк и «сцепляет» слова: читается «Даже · в · Субтитры».

## ransom — буквы-вырезки

```json
{"style": "ransom", "t0": 17.0, "t1": 20.5, "lines": ["ТВОЙ", "БРЕНД"]}
```
| поле | что | по умолчанию |
|---|---|---|
| `lines` | 1–2 слова капсом, до 6 букв (длиннее — буквы уменьшатся) | — |
| `ys` | высоты строк | [420, 590] |
| `step` | пауза между буквами, с | 0.12 |

Это самый «громкий» стиль: весь кадр становится бумагой. Не дольше 3–5 с, один раз за ролик.

## Звук

Звуки не входят в скилл — возьми свою библиотеку UI-звуков. Добавь в план:
```json
"sounds": [{"file": "sfx/whoosh.wav", "t": 4.95, "db": -20}, {"file": "sfx/typing.wav", "t": 12.6, "db": -22}]
```
`t` — секунды итогового ролика, `db` — громкость звука (−18…−25, голос должен оставаться главным).

| момент | звук |
|---|---|
| появление `archive` / `button` | мягкий вуш или тихий «шорох бумаги» |
| квадрат и стрелка (`archive`, +0.4 с) | короткий клик |
| пуговка защёлкивается (`pin_at`) | переключатель / тумблер |
| печатаются DIN-строки (`small_at`, `big_at`) | печатание на клавиатуре, длиной со строку |
| `grain` | тихий шелест или «песок» на всё появление |
| `ransom` | шелест бумаги + щелчки ножниц на буквы |
| уход любого заголовка | ничего или очень тихий вуш |

У вушей и шорохов в начале файла часто тишина: режь звук от пика, иначе он опоздает.
