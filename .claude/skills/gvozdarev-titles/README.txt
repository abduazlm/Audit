Что внутри
Все заголовки из ролика, которые Claude делает в коде:
• «Дизайн архив» — каллиграфия + жирный шрифт, стрелка, подпись, ®, строки на груди
• «Пуговка» — контурное слово + антиква + овал, который сцепляет строки, текст печатается по буквам
• «Слово из зерна» — огромное слово за головой собирается из пыли (для хука)
• «Буквы-вырезки» — журнальные буквы на бумаге, ты вырезан из кадра
Плюс правила: какой стиль на какой момент, как писать текст заголовка и как сделать,
чтобы монтаж не выглядел дешёвым AI. Шрифты уже внутри, бесплатные, с кириллицей.
(Красный заголовок из ролика генерируется нейросетью, в этот файл он не входит.)

Как поставить
1. Откройте Claude Code в папке, где лежит ваш ролик.
2. Перетащите этот архив в чат и напишите: «установи этот скилл в проект».
3. Приложите ролик и напишите: «поставь заголовки из скилла Гвоздарева».

Claude сам расшифрует речь, предложит текст и стиль заголовков, покажет кадры до рендера
и соберёт ролик. Заголовки встают ЗА вами, а не на лицо.

Нужно: Claude Code, Python 3.10–3.14, ffmpeg, Google Chrome. Работает на Mac и Windows.
Первый запуск скачает модель вырезания человека (176 МБ), это один раз.

Если что-то не получилось, напишите мне в Telegram с кодовым словом «текст».
