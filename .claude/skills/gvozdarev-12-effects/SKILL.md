# 12 эффектов Гвоздарева

Ты добавляешь эффекты в готовый (уже нарезанный) вертикальный ролик, где человек говорит в камеру.
Всё рендерит один скрипт `scripts/fx12.py` по плану `plan.json`. Твоя работа: понять, ЧТО человек говорит,
выбрать эффект под смысл, точно поставить его по времени слов, проверить кадры и отдать ролик.

## 0. Установка (один раз)

```bash
pip install "rembg[cpu]"        # потянет numpy, pillow, opencv-python-headless, onnxruntime
ffmpeg -version                  # нужен ffmpeg в PATH (Mac: brew install ffmpeg, Windows: winget install ffmpeg)
```
Если в окружении уже стоит `opencv-python`, а не `-headless`, и `import cv2` падает: удали оба и поставь только
`opencv-python-headless`. При первом запуске rembg скачает модель вырезания человека (176 МБ) в `~/.rembg`.
Python 3.10–3.13.

## 1. Порядок работы

1. **Слова со временем.** Нужна расшифровка с таймкодами слов. Если её нет: Whisper с `word_timestamps=True`
   (Mac: `mlx-whisper`, Windows/Linux: `faster-whisper`). Длинный файл Whisper склеивает и прячет повторы,
   поэтому режь звук на куски по паузам и расшифровывай кусками.
2. **Найди моменты.** Пройди по фразам и отметь, где эффект усиливает смысл (таблица ниже). Не больше одного эффекта
   на мысль и не чаще, чем раз в 2–4 секунды. Лучше 5 точных эффектов, чем 12 подряд.
3. **Окно эффекта = фраза + хвост до 0.5 с.** Эффект живёт, только пока человек говорит о нём, и уходит до следующей
   мысли. `t0` = начало первого слова фразы (можно на 0.03 с раньше), `t1` = конец последнего слова + 0.1–0.5 с.
   Окна не пересекаются.
4. **Напиши `plan.json`** (пример: `examples/plan.json`). Время в секундах исходника.
5. **Контакт-лист до рендера:** `python scripts/fx12.py plan.json --sheet` → `<output>_sheet.jpg`, по 3 кадра
   каждого эффекта. Открой картинку и проверь: текст не на лице, ничего не режется краем, маска не цепляет фон.
6. **Рендер:** `python scripts/fx12.py plan.json`. Звук исходника сохраняется. Скорость около 10–15 с рендера
   на секунду эффекта (CPU), кадры без эффектов идут быстро.
7. **Проверь стыки:** вырежи кадры вокруг начала и конца каждого эффекта (`ffmpeg -ss … -vf tile`) и убедись,
   что нет рывков. Покажи человеку контакт-лист и ролик.
8. Правки: `--only имя,имя` рендерит только нужные эффекты, остальное как в исходнике.

Подробности по каждому эффекту, настройки и звук: `reference/EFFECTS.md`. Список настроек: `python scripts/fx12.py --list`.

## 2. Какой эффект под какие слова

| Эффект (`fx`) | Ставь, когда человек говорит про… |
|---|---|
| `orbit` орбита | свои ролики, портфолио, «сколько я сделал», контент-завод, клиентов |
| `vertigo` вертиго | осознание, шок, «и тут я понял», «всё поплыло» |
| `camzoom` зум камеры | «смотри внимательно», «запомни», разбор, съёмку, камеру |
| `doodle` кипящий контур | лёгкость, творчество, шутку, «я художник», самоиронию |
| `framebreak` выход из рамки | «выйти за рамки», шаблоны, ленту, алгоритмы, Instagram |
| `ransom` буквы-вырезки | громкий тезис, анти-правило, хулиганскую мысль (2 коротких слова) |
| `lens` жидкое стекло | Apple, «стекло», интерфейс, «посмотри поближе», деталь |
| `zoomblur` зум с блюром | акцент, панчлайн, «и вот главное» |
| `figma` выделение | дизайн, Figma, «выделить», ключевое слово, которое хочется «подсветить» |
| `bignum` цифра за головой | перечисления («во-первых», «третий способ»), цифры, топ-N |
| `meme` мем-маятник | эмоцию, иронию, панчлайн (1 мем на ролик, не больше) |
| `spring` пружинный UI | настройки, интерфейсы, «включаем/выключаем», список из 3 пунктов |

## 3. Правила вкуса (иначе выглядит как дешёвый AI-монтаж)

- **Текст и графика никогда не на лице.** Брови, глаза, рот свободны. Крупный текст ниже y≈300 (сверху интерфейс Instagram)
  и выше y≈1650 (снизу подпись и кнопки).
- **За человеком, а не поверх.** Цифры, мемы, задние карточки орбиты уходят за голову по маске. Это и даёт «дорого».
- **Плавно, без обрывов.** Каждый эффект сам входит и сам отдаёт кадр обратно (это уже в коде). Не обрезай окно посреди ухода.
- **Не смешивай.** Один эффект на мысль. Два больших эффекта подряд без паузы утомляют.
- **Мем: маленькая карточка сбоку за головой**, один на ролик, на эмоции. Не на весь экран.
- **Свои ассеты лучше.** Для орбиты возьми обложки роликов человека (`images`), для мема спроси картинку. Без них
  орбита берёт кадры из самого видео.
- **Звук обязателен.** Каждый эффект озвучивается тихим UI-звуком (вуш, клик, тик, переключатель) на 15–25 дБ тише
  голоса. Никаких бумов, импактов и саб-дропов. Шелест и вуш резать по пику, а не с начала файла (в начале тишина).
  Что ставить на какой эффект: `reference/EFFECTS.md`.
- **Шрифты.** Скрипт ищет системные шрифты с кириллицей (Arial Black, Georgia, Impact, Helvetica/Arial). Свой шрифт:
  `"fonts": {"display": "путь.ttf", "medium": "путь.ttf", "italic": "путь.ttf"}` в plan.json.

## 4. Если что-то не так

- Маска цепляет кресло или предмет за спиной: это модель вырезания. Попробуй `"mask_model": "u2net"` или
  `"isnet-general-use"` (медленнее). Кресло в эффекте «буквы-вырезки» обычно выглядит нормально.
- Лицо определилось не там (уголки камеры, мем вылезает не из-за головы): у камеры свет сбоку или человек не в центре.
  Задай точки вручную: `"from"`/`"to"` у мема, `"ui_y"` у камеры.
- Исходник горизонтальный: скрипт обрежет его по центру до 9:16. Если человек не в центре, сначала сделай кроп сам.
- Долго: рендерь `--only` нужные эффекты, смотри `--sheet` вместо полного рендера, пока подбираешь время.
